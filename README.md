# TMPEffect

TextMeshPro에 Outline, Glow, Animation, Curve, MaskFlow 등 모바일 최적화 효과를 추가하는 Unity UPM 패키지입니다.

이 레포지토리는 **개발용 Unity 프로젝트**이며, 패키지 본체는 [`Packages/com.zzamjak.tmpeffects`](Packages/com.zzamjak.tmpeffects)에 임베디드되어 있습니다.

## 설치 (Unity Package Manager → Install package from git URL)

```
https://github.com/zzamjak-cloud/TMPEffect.git?path=/Packages/com.zzamjak.tmpeffects#v1.0.1
```
